## 3.1 UiElement —— 所有 UI 元素基类

UI 是一棵元素树：`UiPanel` 可递归包含子元素；坐标相对父元素像素；命中测试与绘制沿树递归。

### 公开接口

```cpp
// ─── 身份 / 树 ───────────────────────────────────
void setName(const std::string& n);  const std::string& name() const;
UiElement* parent() const;           void addChild(std::unique_ptr<UiElement>);
UiElement* findByName(const std::string& name) const;   // 深度优先
std::vector<std::unique_ptr<UiElement>>& children();

// ─── 布局（相对父元素像素） ──────────────────────
void setPosition(float x, float y);  float x() const; float y() const;
void setSize(float w, float h);      float width() const; float height() const;

// ─── 外观 ────────────────────────────────────────
void setColor(float r, float g, float b, float a = 1.0f);
void setVisible(bool v);             bool visible() const;

// ─── 事件名（JSON on_xxx 字段） ──────────────────
void setNamedEvent(const std::string& key, const std::string& eventName);
const std::string* namedEvent(const std::string& key) const;

// ─── 脏标记 / 上传 ──────────────────────────────
void markDirty();
void uploadShape(const UiRenderContext& ctx);
```

## 3.3 6 个内置控件

| 控件 | 组合 | 关键接口 |
|------|------|---------|
| `UiText` | UiElement | `setText / setFontSize / setFont / setTextColor(r,g,b,a)` |
| `UiButton` | + IClickable + IHoverable | `setText / setFontSize / setFont / setNormalColor / setHoverColor / setPressedColor`；内置三态变色 |
| `UiTextBox` | UiText + ITextInput | 左键点击得全局焦点（同帧仅 1 个）；BACKSPACE/DELETE 删末字符（UTF-8 回溯）；ESC 失焦 |
| `UiPanel` | + IDraggable | `setDraggable(bool) / draggable()`；递归嵌套子元素 |
| `UiSlider` | + IDraggable | `setRange(min,max) / setValue(v) / value() / min() / max() / setTrackColor / setKnobColor / setValueChangedHandler(fn<float>)` |
| `UiCheckbox` | + IClickable | `setChecked(v) / checked() / setBoxColor / setCheckColor / setCheckedHandler(fn<bool>)` |

## 3.4 UiBuilder —— 代码构建 UI（流式 API）

```cpp
class UiBuilder {
    // 顶层元素（替换 m_root）
    UiBuilder& panel(const std::string& name, float x, float y, float w, float h);
    UiBuilder& button(const std::string& name, const std::string& text, float x, float y, float w, float h);
    UiBuilder& text(const std::string& name, const std::string& text, float x, float y, float w, float h);
    UiBuilder& textbox(const std::string& name, const std::string& placeholder, float x, float y, float w, float h);
    UiBuilder& slider(const std::string& name, float x, float y, float w, float h);
    UiBuilder& checkbox(const std::string& name, float x, float y, float w, float h);

    // 子元素（必须在 child() 之后调用）
    UiBuilder& childPanel / childButton / childText / childTextBox / childSlider / childCheckbox(...);

    // 通用属性
    UiBuilder& color(r,g,b,a=1) / visible(v) / fontSize(px) / fontPixel() / fontSmooth(name,size) / font(Font*);
    // 类型特定属性
    UiBuilder& draggable(v=true) / range(min,max) / value(v) / checked(v=true);

    // 事件回调
    UiBuilder& onClick(fn) / onHoverEnter(fn) / onHoverLeave(fn) / onDrag(fn) / onValueChanged(fn<float>) / onChecked(fn<bool>);

    // 树导航
    UiBuilder& child();   // 进入最后子节点（push 栈）
    UiBuilder& end();     // 返回父节点（pop 栈）

    // 完成
    std::unique_ptr<UiElement> build();
    UiElement* current() const;
    template <typename T> T* currentAs() const;
};
```

**语义**：顶层方法只调一次（覆盖 m_root）；属性/事件方法作用于 `m_current`；`build()` 返回根并清空状态。

### UiBindings —— 事件绑定表

```cpp
struct UiBindings {
    std::map<std::string, ClickHandler>  clicks;        // on_click
    std::map<std::string, HoverHandler>  hoverEnters;   // on_hover_enter
    std::map<std::string, HoverHandler>  hoverLeaves;   // on_hover_leave
    std::map<std::string, DragHandler>   drags;         // on_drag
    std::map<std::string, TextInputHandler> inputs;     // on_input
    std::map<std::string, std::function<void(bool)>>  checkeds;      // on_checked
    std::map<std::string, std::function<void(float)>> valueChangeds; // on_value_changed
};
// 链式：click/hoverEnter/hoverLeave/drag/input/checked/valueChanged(name, cb)
```

### JSON 字段参考（支持 JSONC 注释）

| 字段 | 适用元素 | 说明 |
|------|---------|------|
| `type` | 全部（必填） | `panel / button / text / textbox / slider / checkbox` |
| `name` | 全部 | findByName 用 |
| `x / y / width / height` | 全部 | 相对父元素像素 |
| `color` | 全部 | `[r,g,b,a]`，a=0 透明背景 |
| `draggable / children` | panel | 拖拽开关 / 递归子元素 |
| `text / font_size / text_color / placeholder` | text/button/textbox | 文本属性 |
| `min / max / value` | slider | 值域/初始值 |
| `checked` | checkbox | 初始勾选 |
| `on_click / on_hover_enter / on_hover_leave / on_drag / on_input / on_checked / on_value_changed` | 各控件 | 事件名 → UiBindings 查找 |

### 新增自定义控件到 UiLoader（3 步）

1. 派生 `UiMyWidget : public UiElement`（或多继承 I* 接口）；
2. 在 `UiLoader::buildElement` 的 if/else 链加分支 `type == "my_widget"` → `applyCommon` + 读自定义字段；
3. JSON `"type": "my_widget"` 即创建该类。
